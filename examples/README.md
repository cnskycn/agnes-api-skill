## 📁 文件说明

### 1. `test_image_compose.py` - 图片多图合成测试
**功能**：测试角色+场景多图合成，对比5种不同提示词策略

**测试结果**（已验证）：
- ✅ **策略 D**（仅输入场景图+文字描述角色）= 角色外观保留最好
- ✅ **策略 E**（极详细描述）= 总体最佳（场景融合最自然）
- ⚠️ **核心限制**：Agnes AI 多图合成是"参考重生成"，角色外观必然漂移

**使用方法**：
```bash
python test_image_compose.py
```

**输出**：
- 5张测试合成图（PNG格式）
- 对比HTML页面（可在浏览器中查看）

---

### 2. `test_video_gen.py` - 视频生成测试
**功能**：测试角色+场景视频生成，包含多种策略

**测试结果**（已验证）：
- ⚠️ **`keyframes` 模式问题**：角色会慢慢透明消失（图片间插值导致）
- ✅ **推荐方案**：先生成"角色在场景中"的合成图，再用这张图生成视频
- ✅ **正面提示词** 比负面提示词效果更好
- ⚠️ **速率限制**：1次/分钟（需等待70秒）
- ⏱️ **生成时间**：2-4分钟

**使用方法**：
```bash
python test_video_gen.py
```

**输出**：
- 多个测试视频（MP4格式）
- 视频对比HTML页面

---

### 3. `generate_composite_image.py` - 生成合成图（推荐工作流）
**功能**：先生成"角色在场景中"的合成图，用于后续视频生成

**推荐原因**：
- 避免 `keyframes` 模式的插值问题
- 保证角色不会在视频中消失
- 角色和场景真正融合

**使用方法**：
```bash
python generate_composite_image.py
```

**输出**：
- `composite_image.png` - 合成图
- 可直接用于视频生成

---

### 4. `video_from_composite.py` - 从合成图生成视频
**功能**：使用合成图生成视频（避免角色消失问题）

**使用方法**：
```bash
python video_from_composite.py
```

**输出**：
- `output_video.mp4` - 最终视频
- 角色持续可见，不会消失

## 📊 实测经验总结

### 图片合成
1. **策略选择**：优先使用策略 E（极详细描述）
2. **角色一致性**：无法保证100%一致，这是模型固有局限性
3. **替代方案**：如需严格角色一致，使用传统图片叠加（PIL/OpenCV）

### 视频生成
1. **核心问题**：`keyframes` 模式会导致角色消失
2. **解决方案**：先合成图片，再生成视频
3. **提示词**：使用正面描述，避免负面提示词
4. **速率限制**：1次/分钟，建议等待70秒

## 📝 注意事项

## 🐛 故障排除

### 问题1：脚本无输出就退出
**原因**：Python 编码问题（Windows）

**解决**：使用 `-u` 参数运行
```bash
python -u test_video_gen.py
```

### 问题2：速率限制错误
**原因**：1分钟内请求超过1次

**解决**：等待70秒后重试

### 问题3：视频生成超时
**原因**：轮询超时（默认10分钟）

**解决**：增加轮询超时时间，或修改脚本中的 `max_wait` 参数
